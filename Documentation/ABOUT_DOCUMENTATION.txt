--About The Documentation Paradigm--

All reference materials are centrally housed inside the Documentation folder located at the root of the repository.

Every core administrative subject must be fully detailed using a matching pair of specialized informational files.

The framework enforces an absolute segregation between raw technical mechanics and user-facing instructional content.
----------------------------------------------------------------------------------------------------------------------------------------------------------------



----------------------------------------------------------------------------------------------------------------------------------------------------------------
--The Plain Text File Flavor--

The plain text format utilizes the standard .txt file extension to serve as the absolute source of truth for the codebase.

These documents are designed to remain universally readable in any text reader on any operating system without processing.

Each text file acts as a rigid, uniform, and hyper-concise engineering specification stripped of unnecessary fluff or prose.

Every informational statement must be direct, containing nothing but explicit technical facts, definitions, or instructions.
----------------------------------------------------------------------------------------------------------------------------------------------------------------



----------------------------------------------------------------------------------------------------------------------------------------------------------------
--The Markdown File Flavor--

The rich media format utilizes the standard .md file extension and must match the precise base name of its plain text sibling.

These files transform the strict engineering data from the text version into a highly digestible, engaging layout for humans.

The styling resembles a premium, colorful user manual that adds clear aesthetic value for hobbyists who enjoy interacting with it.

The layout heavily leverages markdown tables, clear bullet structures, visual warning blocks, bold text anchors, and color.
