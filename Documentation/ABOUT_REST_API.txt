HRConvert2 accepts input from POST requests over traditional webhooks that support external
scripting & automation tools.

--About The API--

HRConvert2 supports inputs through POST and GET requests.
All requests should be submitted to convertCore.php & all POST requests must be encoded as "multipart/form-data".
If Token1 and Token2 are not submitted via POST input, then convertGui1.php will be displayed prompting for file uploads.
If Token1 and Token2 are both submitted via POST input, then convertGui2.php will be displayed providing conversion options.
The included GUIs make extensive use of JQuery + Ajax to submit requests & process responses.
GUI files cannot handle API requests and will generate an error if they receive API requests.
All API inputs are sanitized by the core for special characters to prevent malicious or unintentional code injection.
As a result of sanitization the filename may change after upload.

To use HRConvert2 via POST & GET requests only:
  1. Submit a blank GET request to convertCore.php to retrieve the value of Token1 and Token2.
  2. Submit a file upload along with Token1 and Token2 to convertCore.php via "multipart/form-data" POST input.
  3. Submit an uploaded filename, a new filename, a file extension, Token1, Token2, and a valid set of conversion options to convertCore.php via POST input.
  4. The core will return a filename to the file that was created, or an error that can be checked against ERROR_DESCRIPTIONS.txt.
  5. Submit a download request for the filename that the core provided to you in the last step.
  6. The core will return a relative URL to the file that will remain valid for --File Deletion Age Threshold-- set in config.php, after which it will be removed.

--About User Supplied GET Requests--

The following is a list of supported GET inputs with description & supported values for each:

  noGui
      GUI Operation, but with no header images or introduction text.
      Display the minimal amount of GUI elements to accomplish the mission.
      Set this input to any value to trigger the UI to display the least amount of elements that is possible.
      This input can also be specified by POST request, but GET will always take precedence.

  showFiles
      Tell the GUI to display uploaded files (convertGui2.php).
      If this is not specified, the upload page is displayed instead (convertGui1.php).
      Valid tokens must be supplied via POST along with this request.

  fileListOnly
      Return the file list as a FRAGMENT rather than as a whole document.
      Set this input to any value to ask for the list on its own.
      Valid tokens must be supplied via POST, & showFiles must be set as well.
      A fragment carries no header & no footer. buildGUI() skips both.
      This exists so a conversion can refresh the list in place without reloading the page
      & closing every panel the user had open.
      A fragment is injected INTO a page that has already loaded the interface helper & the
      script library, so it must never carry a second copy of either. Sending one redefines
      the helper mid flight & re-runs its ready handler, which fetches the fragment again.
      That is a request loop, & every pass destroys the click handlers the previous pass
      registered. Reachable through GET or POST. GET always takes precedence.

  gui
      GUI Operation, with all GUI features
      Select the GUI to use.
      Can be enabled/disabled in config.php.
      Supported GUIs can be added/removed in config.php.
      Set this input to the name of a UI that is installed to the UI folder & defined in config.php.
      This input can also be specified by POST request, but GET will always take precedence.

  language
      GUI Operation
      Select the language to use.
      Can be enabled/disabled in config.php.
      Supported languages can be added/removed in config.php.
      Set this input to the code of an installed language.
      Languages are listed in the --Supported Languages-- section of config.php.
      Most languages are represented by two letter ISO 639-1 codes.
      Aramaic has no ISO 639-1 code, so 'aii' & 'arc' use ISO 639-3 codes instead.

  color
      GUI Operation
      Select the color to use.
      Can be enabled/disabled in config.php.
      Supported colors can be added/removed in config.php.
      Set this input to a supported color scheme defined in config.php.
      This input can also be specified by POST request, but GET will always take precedence.

  sort
      GUI Operation
      The order the file list is drawn in, as two digits. The first is what it is sorted by,
      & the second is the direction.
      The first digit is 1 for the name, 2 for the size, 3 for the time a file changed & 4 for
      its type, which is its extension. The second is 1 for ascending & 2 for descending.
      11 is the default, & lists by name from A to Z. 22 lists the largest first.
      Files that tie are listed by name, in natural order, so file2 comes before file10.
      A value that is not two such digits lists by name, & is logged as a warning.
      Every link & form an interface draws carries it, so the order survives a refresh, a
      change of language & every operation that draws the list again.
      Reachable through GET only.

--About User Supplied POST Requests--

The following is a list of supported POST inputs, organized into sections based on when they are used, with description & supported values for each:

  General Use
      Token1
          String.
          This input is used whenever a user intends to use HRConvert2.
          This input is provided to the user by HRConvert2 via a hidden form field.
          This value must be stored & resubmitted with every subsequent request that is part of the same session.
          Set this input to the value of the hidden form field from convertGui1.php that has an 'id' of 'Token1'.
      Token2
          String.
          This input is used whenever a user intends to use HRConvert2.
          This input is provided to the user by HRConvert2 via a hidden form field.
          This value must be stored & resubmitted with every subsequent request that is part of the same session.
          Set this input to the value of the hidden form field from convertGui1.php that has an 'id' of 'Token2'.

  General File Operations
      file
          Multipart file field, or file[] for several files at once.
          This input is used to upload files. An upload happens whenever a file is posted with
          valid tokens, & no other input is needed to trigger it.
          An upload fails with error 18 when the listener refuses it, because the disk holding the
          session has --Storage Reserve-- megabytes free or less, or would have once it was written.
      download
          String or JSON Array.
          This input is used at any time to download user files.
          This input is used to generate file URLs for sharing operations.
          Set this input to a name or list of names to use for input files.
      filesToDelete
          String or JSON Array.
          This input is used at any time to delete user files.
          Set this input to a name or list of names to use for input files.

  File Conversion Operations
      convertSelected
          String or JSON Array.
          This input is used during File Conversions (excluding OCR & bulk archiving)
          Set this input to a name or list of names to use for input files.
      extension
          String.
          This input is used during File Conversions (excluding OCR & bulk archiving)
          Set this input to an extension to use for the output file.
      userconvertfilename
          String.
          This input is used during File Conversions (excluding OCR & bulk archiving)
          Set this input to a name to use for the output file.
          A name already in the session is given the next free one, such as name_1, & the
          reply names the file that was written.

  Image Conversions
      height
          Integer.
          This input is used during Image Conversions.
          Image height in number of pixels to use for the output file.
          Set this input to 0 to not resize the original image.
      width
          Integer.
          This input is used during Image Conversions.
          Image width in number of pixels to use for the output file.
          Set this input to 0 to not resize the original image.
      rotate
          Integer.
          This input is used during Image Conversions.
          Number of degrees to rotate the image clockwise.
          Set this input to 0 to not rotate the original image.

  Audio Conversions
      bitrate
          Integer.
          This input is used during Audio Conversions.
          Bitrate to use for the output file.
          Set this input to 0 to use automatic bitrate detection.

  Archive Operations
      archive
          String.
          This input is used during Archive Operations (excluding conversions).
          Set this input to any value to trigger archive operations.
      userfilename
          String.
          This input is used during Archive Operations (excluding conversions).
          Set this input to the name to use for the output file.
          A name already in the session is given the next free one, such as name_1, & the
          reply names the file that was written.
      archextension
          String.
          This name is all lower case. The core reads $_POST['archextension'] & nothing else.
          This input is used during Archive Operations (excluding conversions).
          Set this input to an extension to use for the output file.
      filesToArchive
          String or JSON Array.
          This input is used during Archive Operations (excluding conversions).
          Set this input to a name or list of names to use for input files.

  Optical Character Recognition (OCR) Operations
      pdfworkSelected
          String or JSON Array.
          This input is used during OCR Operations.
          Set this input to a name or list of names to use for input files.
      userpdfconvertfilename
          String.
          This input is used during OCR Operations.
          Set this input to a name to use for the output file.
          A name already in the session is given the next free one, such as name_1, & the
          reply names the file that was written.
      pdfextension
          String.
          This input is used during OCR Operations.
          Set this input to an extension to use for the output file.
      method
          Integer, 0 or 1.
          This input is used during OCR Operations.
          This input determines the internal method to use for performing the conversion.
          Set this input to 0 to use a simple approach to OCR.
          Set this input to 1 to use a more advanced approach to OCR.

  Virus Scanning Operations
      scantype
          String (clamav or scancore or all).
          This input is used during Virus Scanning Operations to scan a specific file.
          Set this input to 'clamav' to perform a virus scan with ClamAV Virus Scanner.
          Set this input to 'scancore' to perform a virus scan with ScanCore Virus Scanner.
          Set this input to 'all' to perform a virus scan with all installed Virus Scanners.
      filesToScan
          String or JSON Array.
          This input is used during Virus Scanning Operations & is what triggers one.
          Set this input to a name or list of names to use for input files.
          This name is camel case. The core reads $_POST['filesToScan'] & nothing else.
          The interface's scan buttons post scantype & filesToScan & nothing else. To scan every
          file, name every file. The button names clamscanbutton, scancorebutton & scanallbutton
          are not read by the core.

  Remote File Operations
      userURLDownload
          String.
          This input is used to fetch a file from a remote address into the session.
          It is read as an address rather than sanitized as a filename, & every check a stream
          address receives is applied to it before anything is fetched.
          Requires --Allow User URL Download-- in config.php.
      streamBaseURL
          String.
          This input is used during Stream Conversions to resolve relative playlist entries.
          It is read as an address & rebuilt from its parsed parts at the point of use.

  File Identification Operations
      filesToIdentify
          String or JSON Array.
          This input is used during Identify Operations & is what triggers one.
          Set this input to a name or list of names to use for input files.
          Identifying changes no file. Each one is hashed, & the tools installed say what it holds.
          A name the session does not hold is skipped & logged, & the rest are still identified.
          This name is camel case. The core reads $_POST['filesToIdentify'] & nothing else.
          Requires --User File Identification-- in config.php. When it is off, the reply is the
          sentence Identifying files is disabled on this server.
      identifyreport
          String, 0 or 1.
          This input is used during Identify Operations.
          Set this input to 1 to write a report of every file identified into the session.
          Anything else writes no report, & the reply alone describes the files.
      identifyfilename
          String.
          This input is used during Identify Operations when a report is written.
          Set this input to a name for the report, without its extension. A report is always txt.
          User_Identify_Report is used when it is empty.
          A name already in the session is given the next free one, such as name_1, & the
          reply names the file that was written.

      The reply is one line of JSON, after the doctype line that opens every reply.
        {"Identify":{"Complete":true,"Errors":false,"Report":"","Records":[...]}}
      Complete is false when no file was identified, or when a report was asked for & was not
      written, & error 31 follows the JSON.
      Errors is true when anything was skipped or failed, even when Complete is true.
      Report is the name of the report that was written, or empty.
      Records holds one object for every file identified, with these keys.
        Name                The file.
        Size, SizeText      Its size in bytes, & in words such as 1.2 KB.
        Modified            When it last changed, as YYYY-MM-DD HH:MM in the server's time.
        Description         What file says it holds, or empty when file could not be asked.
        MimeType, Charset   Its MIME type & character set, from file.
        ExtensionMatches    yes, no or unknown. Whether its extension is one file expects.
        ExpectedExtensions  The extensions file expects for what it holds.
        SHA256, SHA1, MD5   Its hashes, in lower case hexadecimal.
        Details             A list of sentences describing what the tools read.
        Notes               A list of sentences about anything unusual, & any tool not asked.
        Text, Image, Media, Pdf, Archive
                            Present where they apply. What the tool for that kind of file read.
      Every character that means something in HTML is escaped, & so is the exclamation mark,
      so nothing a file carries can spell the tag an interface reads as an error.
